ARKN Extension: System Context & Technical Mandate1. Product Overview & Core VisionARKN is a localized, privacy-first compliance layer designed specifically for professionals in highly regulated UK industries (e.g., solicitors, financial advisers, and accountants) who use generative AI tools like ChatGPT.  The application must automatically catch personal identifiable information (PII) before it leaves the browser, substitute it with transparent tokens, and restore the original data completely on the client side when displaying the AI's response.  The Core MandateEvery action must happen locally on the user's machine. No raw message text, prompt data, or unredacted PII should ever be transmitted to any external server, including our own.  2. Technical Constraints (Manifest V3 Architectural Rules)To maintain a flawless user experience without breaking the internal React/state engines of AI platforms, the extension must adhere to the following architecture:  No Direct DOM Input Alteration: Do not modify text directly inside the web page's input text fields, as this causes UI framework desynchronization. Intercept at the network boundary instead.  Main Window Isolation: Since standard content scripts run in an isolated execution world, network interception must be handled by an injected script executing directly in world: "MAIN".  Session Isolation: All local token dictionaries must be scoped tightly by the unique AI Session/Conversation UUID parsed from the browser URL or HTTP payloads.  Air-Gapped Compliance: The entire data substitution, local logging, and UI unmasking pipeline must remain fully functional when the browser is disconnected from the internet.  3. Data Schema & Tokenization StrategyOutbound Redaction TargetWhen a network payload matching /backend-api/conversation is captured, the text must be scrubbed using local matching engines.  Fixed Data (Regex): Ultra-fast patterns targeting emails, phone numbers, and postcodes.  Variable Data (Local NER): A lightweight On-Device AI framework targeted specifically at extracting Names and Organizations safely.  Metadata Audit Logging (The Moat)When PII is caught, the extension must write a zero-PII entry into chrome.storage.local to fuel a 30-day exportable compliance history.  Allowed Log Metadata: Timestamps, target AI engine, and integers representing count types (e.g., names: 2, emails: 1).  Forbidden Log Data: The original string contents, modified tokens, hashes of the text, or surrounding contextual text must never be saved permanently to disk.  4. UI/UX Insertion GuidelinesStealth Baseline: While running, the extension should stay visually transparent so the user can chat as normal.  The Calm Note: Inject brief, styled HTML alerts directly under the processed message blocks to confirm protection occurred without re-stating the PII (e.g., "🛡️ ARKN protected 2 names in this message.").  Visual Unmasking: Utilize a fast MutationObserver on the response panels to swap tokens like [NAME_1] out for their original local state values seamlessly before the user reads them.
